REDESIGNED BY TELLF5IVE 🔥

Modern redesigned ox_inventory UI with a cleaner layout, refreshed styling, improved item slots, and polished visuals for FiveM roleplay servers.

Installation

Download the redesigned ox_inventory.
Replace your existing ox_inventory UI files with the redesigned files.
Add or keep this in your server.cfg:
ensure ox_inventory
Make sure ox_inventory is started after your framework.
Supported frameworks: QBCore, ESX, and Qbox.
Restart your server and clear cache if needed.

This is a visual redesign only. Core inventory functionality remains based on the original ox_inventory.
